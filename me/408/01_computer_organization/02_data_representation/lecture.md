## 2. 必会概念

### 2.1 机器数三兄弟（n 位）

以正数 `+5`、负数 `-5`，设字长 **8 位** 为例：

| 编码 | +5 | -5 | 要点 |
|------|-----|-----|------|
| 原码 | `0000 0101` | `1000 0101` | 最高位符号，其余是绝对值 |
| 反码 | `0000 0101` | `1111 1010` | 正数=原码；负数=原码除符号位外按位取反 |
| 补码 | `0000 0101` | `1111 1011` | 正数=原码；负数=反码+1（或：绝对值取反加一） |

**记法（负数求补码，最快）：**  
写出绝对值的原码 → **按位取反再加 1**。

### 2.2 补码能表示的整数范围（必背）

字长 n 位补码：

- 最小：`-2^(n-1)`  
- 最大：`2^(n-1) - 1`  

例子：
- 8 位：`-128 ~ +127`  
- 16 位：`-32768 ~ +32767`  
- 32 位：`-2^31 ~ 2^31-1`

注意：**没有“+128”的 8 位补码**；`1000 0000` 表示的是 **-128**。

### 2.3 补码加减怎么算

统一成加法：

- `A + B`：直接补码相加，丢弃超出 n 位的进位（模 `2^n`）  
- `A - B`：做成 `A + (-B)`，其中 `(-B)` 的补码 = 对 B 的补码再取补（取反加一）

结果仍是补码，需要时再转真值。

### 2.4 溢出 OF vs 进位/借位（CF）——高频坑

| | 看什么 | 含义 |
|--|--------|------|
| **溢出 OF** | 两个**有符号数**运算后，结果是否仍落在补码范围内 | 符号“算崩了” |
| **进位 CF**（加法） | 最高位有没有进位出去 | 对**无符号数**有意义 |

判断溢出（常用两种，会一种即可）：

1. **符号法**：两正数相加得负，或两负数相加得正 → 溢出  
2. **进位法**：次高位进位 ⊕ 最高位进位 = 1 → 溢出  

**关键：** 有进位 ≠ 一定溢出；有溢出 ≠ 一定有进位。  
408 问“溢出标志”时，多半问的是 **OF（有符号）**。

### 2.5 算术移位（常和补码一起考）

- **算术右移**：高位补**符号位**（保持符号）  
- **算术左移**：低位补 0；若符号改变则溢出/结果错误

## 3. 题型 + 标准步骤

### 题型 A：给位数，问补码表示范围

**步骤：** 套公式 `-2^(n-1) ~ 2^(n-1)-1`，别写成 `±2^(n-1)`。

### 题型 B：真值 ↔ 补码

**真值→补码：**  
1. 看正负  
2. 正：原码即补码（注意位数）  
3. 负：绝对值原码 → 取反加一  

**补码→真值：**  
1. 看符号位  
2. 正：直接读后面的值  
3. 负：再取反加一得到绝对值，前面加负号（或按权展开）

### 题型 C：补码加减 + 是否溢出

**步骤：**  
1. 两数都写成 n 位补码  
2. 减法先变加相反数  
3. 相加得 n 位结果  
4. 用符号法或双进位法判 OF  
5. 若问真值，再转换；若已溢出，选项里常有“溢出”或错误结果

### Q1. 为什么正数的原码、反码、补码都一样？为什么负数的原码是第一位变成 1？反码和补码又是怎么算出来的？

（你原话大意：正数三种为什么一样；负数原码为何第一位变 1；反码、补码怎么算。）

**答：**

正数三种一样，是因为定义就是这样：正数符号位 `0`，后面放绝对值；反码/补码对正数不做变换。所以 `+5` 三种都是 `0000 0101`。可以记：**正数不用折腾，三种长一样。**

负数原码第一位是 1，因为原码用最高位当**符号位**：`0` 正、`1` 负；后面仍是绝对值。所以 `-5` 原码 = 符号改成 1 + 绝对值 5 → `1000 0101`。第一位变 1 **不是数值变大，只是标记这是负数。**

负数反码：符号位保持 1，其余位按位取反。  
`-5`：原码 `1000 0101` → 反码 `1111 1010`。

负数补码（两种等价，会一种即可）：  
- 方法 A（最常用）：写出绝对值原码 → **全体按位取反再 +1**  
- 方法 B：先求反码，再 +1  

`-5`：`0000 0101` → 取反 `1111 1010` → +1 `1111 1011`。

考试固定流程：求负数补码 = 绝对值二进制 → 按位取反 → 加 1。

---

### Q2. 这个「加 1 / 全体按位取反再 +1」是加 `0000 0001` 吗？

**答：**  
对。**加 1** 就是在二进制里加上 `0000 0001`（8 位就是这个）。

以 `-5` 为例：

```
绝对值 +5:   0000 0101
全体取反:     1111 1010
再 +1:        1111 1010
            + 0000 0001
            -----------
              1111 1011   ← -5 的补码
```

注意：这是二进制加法进位，不是在十进制意义上随便加点什么。

**第二轮（仍有错）：** 写成了 `0000 0100`（那是 4）。

### Q4. 「用补码可以把减法和加法统一成一套加法电路，硬件更简单；而且 0 只有一种表示。」我没有理解这句话。

**答（还原讲解结构）：**

**（1）「减法和加法统一成一套电路」**  
人算 `7-3` 是减法；机器更想只做加法。补码规矩是：

`A - B = A + (-B)`

`(-B)` 在补码里就是对 B 取反加一得到的码。硬件只要有：一个加法器 + 一个「取反加一」的小动作。所以减法也变成「加上一个负数的补码」，电路主要围着加法转。

**（2）若用原码，减法更烦**  
原码里 `+3` 和 `-3` 只是最高位不同，不能直接当普通二进制加；符号要单独处理，分支多。补码把负数编成可以直接拿去加的比特串，所以简单。

**（3）「0 只有一种表示」**  
原码：`+0=0000 0000`，`-0=1000 0000`，两个都叫零。  
补码：只有一种零（见下一问你纠正后的准确说法）。

**（4）小例子**  
`5-3` 在 8 位补码里就是 `5+(-3)`：

```
+5:     0000 0101
-3补码: 1111 1101
相加:   0000 0010   → +2
```

表面上加法，完成的是减法。

可记短版：补码让「减一个数」变成「加它的相反数」，机器主要会加法就行；而且零不会有两种写法。

### Q6. 「-1 是 1111 1111，不会再搞出一个负零」这里举例错误了吧？是 -0 的补码也是 0000 0000，所以对补码来说 +0、-0 都是 0000 0000？

**答：**  
你说得对，这里是老师举例容易让人误会。

补码里：  
- `+0` → `0000 0000`  
- 对 0 再求相反数（取反加一）：`0000 0000` → 取反 `1111 1111` → +1 → 进位出去后还是 `0000 0000`  
- 所以 `-0` 也是 `0000 0000`，和 `+0` 同一个码  

也就是说：补码里没有两种零；`+0`、`-0` 都是全 0。  
而 `1111 1111` 是 **-1**，和“负零”无关。老师前面把「-1」和「不会有负零」写在一块，容易听成 `1111 1111` 跟负零有关——**你的纠正是对的。**

| | 原码 | 补码 |
|--|------|------|
| +0 | `0000 0000` | `0000 0000` |
| -0 | `1000 0000`（另一种零） | 还是 `0000 0000`（同一种） |

### Q7. 机器数 `1011 0100`（8 位补码）真值？你做到「转十进制怎么转」这一步时的过程对不对？

**答：**  
你最后得到的 `0100 1100` 是对的，但中间思路偏了。这题是补码→真值，**不是**“加 -1”。

正确做法（符号位 1 = 负数）：  
1. 全体取反：`1011 0100` → `0100 1011`  
2. 再 +1 → `0100 1100`  
3. 前面加负号 → 真值 **-76**（选 A）

你笔记里「要 -1 / 加 -1 / 和 `1111 1111` 相加」不是标准步骤，容易绕晕；后面碰巧搞到 `0100 1100`，过程不可复用。请固定：

> 负补码 → 真值：取反加一得绝对值，再加负号。

`0100 1100` 转十进制（按权相加）：  
位权 128,64,32,16,8,4,2,1 → 有 1 的是 64+8+4=76 → 真值 -76。

### Q8. 第 4 题 `(+100)+(+50)` 是什么意思？借位是啥意思？

**答（第 4 题）：**  
考的是 8 位有符号补码加法会不会装不下。人算 150，但 8 位补码最大 127。

```
+100:  0110 0100
+50:   0011 0010
相加:  1001 0110
```

最高位是 1，按有符号像负数；两正相加却变“负长相”→ 溢出。也可用范围：150>127 → 一定溢出。答案 **B**。  
A 错（装不下 150）；C 比特串对但就是溢出；D 不是借位，-106 是溢出后误读的假真值。

**借位：** 做**减法**时不够减就向高位借（类似十进制 32-5 个位借十）。二进制某位是 0 要减 1，就向左边借。  
第 4 题是加法，选项说「借位」用错场景；该谈的是溢出。

### Q9. 第 5 题「关于溢出判断，正确的是？」

**答：** 答案 **B**——两正数相加得负数，一定溢出。

- A ✗ 最高位有进位 ≠ 一定溢出。进位更多用于无符号；有符号看 OF。例：`(-1)+(-1)` 有进位，结果 -2，没溢出。  
- B ✓ 符号判断法：两正相加得负，或两负相加得正 → 一定溢出。  
- C ✗ 无符号进位/借位 ≠ 有符号溢出 OF。  
- D ✗ 溢出后留下错误比特，不一定全 0（第 4 题是 `10010110`）。

### Q10. 课件里「`(-B)` 的补码 = 对 B 的补码再取补（取反加一）」——是不是其实是对 B 的原码取反加一，一个意思？因为正数原反补一样；但原理还是对 B 的补码取反+1？对补码再补，就是负数的补码了，对吗？

**答：**  
大方向对，补一句限定更准。

要算 `A-B`，做成 `A+(-B)`。`(-B)` 的机器数 = 对当前 **B 的补码** 再取反加一。这叫「对补码再取一次补」，得到的就是 **-B 的补码**。你说「对补码再补，就是这个数相反数的补码」——对。

和「对 B 的原码取反加一」是不是一回事？  
- **B 为正时：是一回事**（原码=反码=补码）。  
- **B 为负时：不要对原码做，要对补码做**（原码≠补码；机器里参加运算的是补码）。

统一操作：不管 B 正负，都对 **B 的补码** 取反加一 → `-B` 的补码。  
考试记：求相反数，对该数的**补码**取反加一（正负数都适用）。

### Q11. 所以正数和负数的补码，取反+1 都可以推出对方是吗？

**答：**  
对（你说的「复数」这里是负数）。正数、负数的补码，取反加一，一般都能得到对方（相反数）的补码。

```
+3:  0000 0011  --取反+1→  1111 1101  (-3)
-3:  1111 1101  --取反+1→  0000 0011  (+3)
```

记：补码体系里，取反加一 = 取相反数；正负可以互推。

### Q12. -128 的补码取反加一还是 -128 的补码，对吗？因为就没有 +128，是不是？

**答：**  
对。8 位补码里有 `-128`（`1000 0000`），没有 `+128`（最大只有 +127）。  
所以对 `-128` 再取反加一，结果还是 `1000 0000`，表示的还是 -128（这一步溢出，得不到真正的 +128）。  
不是绕口令，而是：想取相反数时，相反数 +128 根本存不下，所以还停在 -128 那个码上。
