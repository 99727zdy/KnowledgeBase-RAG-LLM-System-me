## 怎么用（上课）

1. 学某章时，打开对应科目的 `by_topic/….md`  
2. 按表里的「年份 + 题号」打开 `exams/202X_exam.pdf` 做题  
3. 对答案看 `202X_answer.pdf`  
4. 不会的记进该科 `error_log.md`
